# OrderUp resource pack

The built resource pack for OrderUp, a Minecraft server by [Xena Studios](https://xenastudios.co). Minecraft clients download it from here when they join; there's nothing to do with it by hand.

- `orderup-pack.zip`: the newest pack
- `orderup-pack.sha1`: its SHA-1, and which copy in `packs/` it is
- `packs/<sha1>.zip`: the last ten packs, by hash

Published automatically by the game's build; the source is private. © Xena Studios, all rights reserved.
